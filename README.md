## Project Overview

The Bethel Fashion Website is a web development project created for Bethel Fashion as part of the WEDE5020 Web Development (Introduction) Portfolio of Evidence.

The purpose of the project is to create a functional, informative and visually appealing website that provides users with information about Bethel Fashion and its products. The website is designed to provide a clear online presence for the organisation and make it easier for visitors to navigate through the available information.

The website uses HTML for structure, CSS for styling and responsive design, and a small amount of JavaScript for interactive behaviour. It contains five main pages: Home, About, Collections, Enquiry, and Contact.

## Website Goals and Objectives

The main goal of the website is to establish a professional online presence for Bethel Fashion while providing users with clear and accessible information about the organisation and its fashion collections.

The objectives are:

* Provide visitors with an introduction to Bethel Fashion.
* Present information about the organisation through the About page.
* Showcase the available fashion collections and products.
* Provide an enquiry page where visitors can submit product related enquiries.
* Provide contact information so that visitors can reach the organisation.
* Create clear and consistent navigation between all website pages.
* Apply a modern and elegant visual identity using a black, white, cream and gold colour scheme.
* Ensure the website is fully responsive across desktop, tablet and mobile devices.

## Key Features and Functionality

### Home Page
* Hero section with a large editorial image and brand introduction.

* Call to action button linking to the Enquiry page.

### Collections Page

### Enquiry Page

* Submit button styled with the gold accent.

### Contact Page
* Contact information blocks for address and phone numbers.
* Two embedded Google Maps iframes showing the two store locations.
* Contact form with name, email, phone number and message fields.

### Shared Site Features
* Sticky header with a logo and navigation menu.
* Shopping Bag link in the header.
* Responsive footer with four columns: brand, quick links, customer care and contact.
* Hover and focus states on all interactive elements for accessibility.

Part 1 Details
Part 1 of the Bethel Fashion website project focused on planning, research, initial development and documentation. The following activities were completed:

Researched Bethel Fashion and gathered relevant information for the website.

Defined the purpose, goals, objectives and target audience of the proposed website.

Analysed the organisation current online presence and identified areas for improvement.

Planned the website structure and navigation.

Created a sitemap showing the relationship between the main website pages.

Created low fidelity wireframes for the layout and information hierarchy.

Developed the initial HTML structure for the website.

Created the five main website pages: Home, About, Collections, Enquiry and Contact.

Added researched content and relevant images to the website.

Implemented navigation links between the website pages.

Tested the HTML pages and navigation to identify and correct errors.

Organised the website files and images into a clear folder structure.

Created and maintained the private GitHub repository for the project.

Part 2 Details
Part 2 focused on CSS styling and responsive design. The following activities were completed:

Created an external stylesheet in the css folder and linked it to all five HTML pages.

Applied a CSS reset based on the Meyer reset to remove default browser styling.

Defined CSS variables for the colour palette (black, cream, white and muted gold), fonts, spacing and layout constants.

Applied typography using Playfair Display for elegant serif headings and Inter for clean body text from Google Fonts.

Built the layout using CSS Grid for major page sections and Flexbox for the navigation, cards and footer.

Styled buttons, cards, forms and the footer with visual properties such as colour, borders, border radius, box shadows and smooth transitions.

Added hover and focus pseudo classes to all interactive elements for accessibility.

Implemented two media query breakpoints at 900px for tablet and 600px for mobile.

Adjusted the layout at each breakpoint: single column sections, stacked cards, and a horizontally scrollable navigation on tablet.

Converted fixed font sizes to responsive units using clamp, rem and vw.

Ensured all images scale correctly using max width 100 percent and object fit cover.

Added descriptive alt text to every image for accessibility and SEO.

Added meta descriptions and keywords to each HTML page.

Tested the website in Chrome at desktop, tablet and mobile widths and captured screenshot evidence.

## Part 3: JavaScript Functionality, Forms, SEO and Deployment
