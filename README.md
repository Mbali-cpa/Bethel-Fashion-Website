## Project Overview

The Bethel Fashion Website is a web development project created for Bethel Fashion as part of the WEDE5020 Web Development (Introduction) Portfolio of Evidence.

The purpose of the project is to create a functional, informative and visually appealing website that provides users with information about Bethel Fashion and its products. The website is designed to provide a clear online presence for the organisation and make it easier for visitors to navigate through the available information.

The website has been developed using HTML as the foundation of the project. The initial structure contains five main web pages: the Home page, About page, Collections page, Enquiry page and Contact page. The pages are connected through a navigation menu to provide consistent navigation throughout the website.

The project also includes an organised images folder containing the visual assets used throughout the website.

## Website Goals and Objectives

The main goal of the website is to establish a professional online presence for Bethel Fashion while providing users with clear and accessible information about the organisation and its fashion collections.

The objectives of the website are to:

- Provide visitors with an introduction to Bethel Fashion.
- Present information about the organisation through the About page.
- Showcase the available fashion collections and products.
- Provide an enquiry page where visitors can submit product-related enquiries.
- Provide contact information so that visitors can communicate with the organisation.
- Create clear and consistent navigation between all website pages.
- Organise website content using appropriate HTML structure.
- Create a foundation that can be further developed with CSS and JavaScript in later parts of the PoE.

## Part 1 Details

Part 1 of the Bethel Fashion website project focused on the planning, research, initial development and documentation of the website.

The following activities and deliverables were completed as part of Part 1:

- Researched the selected organisation, Bethel Fashion, and gathered relevant information for the website.
- Defined the purpose, goals, objectives and target audience of the proposed website.
- Analysed the organisation's current online presence and identified areas that could be improved through the proposed website.
- Proposed the main website features and functionality based on the needs of the organisation and its target audience.
- Planned the structure and navigation of the website.
- Created a sitemap showing the relationship between the main website pages.
- Created low-fidelity wireframes to plan the layout and information hierarchy of the website.
- Developed the initial HTML structure for the website.
- Created the five main website pages: Home, About, Collections, Enquiry and Contact.
- Added researched content and relevant images to the website.
- Implemented navigation links between the website pages.
- Tested the HTML pages and navigation to identify and correct errors.
- Organised the website files and images into the project structure.
- Created and maintained the private GitHub repository for the project.
- Added the initial website files and images to the GitHub repository.
- Created and updated the README.md documentation for the project.

Part 1 establishes the foundation of the Bethel Fashion website. Further development in Parts 2 and 3 will focus on styling, responsiveness, JavaScript functionality, SEO and additional website functionality.
